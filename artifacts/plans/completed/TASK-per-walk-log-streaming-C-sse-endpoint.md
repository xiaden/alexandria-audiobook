# Task: Per-Walk Log Streaming Part C — SSE Endpoint

## Problem Statement
Part C exposes the Part A process-local JSONL/broker service through the mounted
pipeline API and changes the two walk-start endpoints to use Part B's API-owned
reservations. Clients need a secure, replayable `text/event-stream` for one
validated `walk_run`, while the database remains the status authority and a
disconnect must never interfere with synchronous walk execution. Parts A and B
define the sink/subscription and reserved-run contracts; this plan only wires
those contracts into `api_walks.py` and its backend tests, without changing any
walk module or runner internals.

**Prerequisite:** `TASK-per-walk-log-streaming-A-walk-log-service-core.md` and
`TASK-per-walk-log-streaming-B-runner-integration.md`.
